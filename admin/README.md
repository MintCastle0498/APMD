# APMD 콘텐츠 관리 도구

News / People / Publication에 새 글·인물·논문을 코드를 직접 안 건드리고 추가할 수 있는
내부용 도구입니다. 서버나 로그인 없이, 브라우저가 여러분 컴퓨터의 이 프로젝트 폴더에
직접 파일을 쓰는 방식으로 동작합니다 (Chrome/Edge의 File System Access API).

## 실행 방법

이 페이지는 `file://`로 그냥 열면 폴더 선택 기능이 동작하지 않습니다 (브라우저 보안 정책).
로컬 서버로 띄워서 열어야 합니다:

```
cd "APMD Web"
python -m http.server 8000
```

그 다음 브라우저(Chrome 또는 Edge)에서 `http://localhost:8000/admin/` 접속.

## 사용법

1. "사이트 폴더 선택" 버튼 클릭 → 이 `admin` 폴더의 **부모 폴더** (`APMD Web`, 즉
   `index.html`, `scripts/`, `News/` 등이 있는 폴더)를 선택.
2. 상단 탭(News / People / Publication)에서 원하는 걸 고르고, 폼에 내용을 입력 +
   사진 첨부 후 "추가하기".
3. 사진은 자동으로 올바른 폴더(News/, People/, Publication/)에 복사되고, 해당 데이터
   파일(scripts/*.js)에 새 항목이 자동으로 추가됩니다.
4. 오른쪽 목록에서 항목을 바로 "삭제"할 수도 있습니다 (사진 파일 자체는 지워지지
   않습니다 — 필요하면 폴더에서 직접 지워주세요).
5. "수정"을 누르면 그 항목 내용이 폼에 그대로 채워지고, 버튼이 "수정 완료"로
   바뀝니다. 내용을 고친 뒤 "수정 완료"를 누르면 그 항목만 바뀝니다 (사진/이미지
   입력을 비워두면 기존 사진을 그대로 유지). "취소"를 누르면 새 항목 추가 모드로
   돌아갑니다.

## 이후 할 일 — 실제 사이트에 반영하기

이 도구는 여러분 컴퓨터의 파일을 직접 수정할 뿐, 실제 배포된 사이트나 GitHub에는
아무것도 하지 않습니다. 항목을 다 추가했으면 평소처럼:

```
git add -A
git commit -m "..."
git push
```

(또는 Claude에게 "커밋해서 올려줘"라고 요청)

## 알아두면 좋은 점

- 기존에 손으로 정성껏 정리된 파일 포맷(들여쓰기, 스타일)은 건드리지 않습니다 — 새
  항목만 각 배열 끝에 추가되고, 기존 항목은 삭제할 때 말고는 한 글자도 안 바뀝니다.
- "수정"은 그 항목의 텍스트만 새로 씁니다 — 나머지 항목들은 한 글자도 안
  바뀝니다.
- 이 페이지는 사이트에 같이 올라가서 `.../admin/`으로 접속하면 누구나 열어볼 수는
  있지만, 실제로 파일을 쓰는 건 그 사람 "자기 컴퓨터의 로컬 폴더"에만 해당돼서
  (직접 폴더를 골라야 함) 이 사이트 자체에는 아무 영향이 없습니다.
